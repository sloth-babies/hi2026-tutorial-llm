# HI2026 コース3 Webサイト仕様

ステータス: Draft v0.1
更新日: 2026-09-04

## 1. 目的

ヒューマンインタフェースシンポジウム2026の講習会コース3「LLM活用入門から応用まで：プロンプト設計・LoRA・RAG」を、開催前の参加者案内と開催後の教材アーカイブの両方として案内する。

参加者が最初に知りたい情報を短時間で把握し、そのまま演習用Colabへ進めることを最優先とする。

## 2. 対象者

- シンポジウムでコース3を受講する参加者
- LLM活用、プロンプト設計、RAG、LoRAに関心のある研究者・学生・実務者
- 開催後に教材や演習内容を参照する人

## 3. 初期スコープ

### 含めるもの

- 1ページの静的サイト（トップページのみ）
- コース概要、日時、会場、学習内容
- 演習用Colabへの外部リンク
- 講義資料PDFへのリンク
- 講師紹介と、提供されたホームページへのリンク
- ヒューマンインタフェースシンポジウム2026公式サイトへのリンク
- 開催前・開催後のどちらでも読める文面
- スマートフォン、タブレット、デスクトップへのレスポンシブ対応
- キーボード操作、十分なコントラスト、外部リンクの明示

### 初期スコープに含めないもの

- 参加登録フォーム
- CMSや管理画面
- ログイン、会員限定機能
- サイト内検索
- コメント、チャット、問い合わせフォーム
- 講習会全体やシンポジウム全体の情報の再掲載

## 6. 開催前・開催後の扱い

### 開催前

- CTAは「演習用Colabを開く」
- 日時、会場、参加方法など未確定情報は掲載しない
- 公開済み資料だけを案内する

### 開催後

- CTAの文言を「演習用Colabを見る」または「演習を始める」に変更可能にする
- 「講義資料」「演習リンク」をアーカイブとして残す
- 必要に応じて開催済みであることを表示する

## 7. デザイン方針

「白い紙面に、墨色の文字と焦がしオレンジを添える」ことを視覚的なテーマとする。

- 白い背景に、墨色〜濃紺の文字
- プライマリーカラーは焦がしオレンジ系を1色だけ使用
- 細い罫線と余白で情報を整理する
- 大きな装飾画像や過剰なアニメーションは使わない
- 見出しは端正に、本文は読みやすく、外部リンクは明確に区別する
- 見出しは柔らかいサンセリフ、本文は読みやすいゴシック体を使う
- カードや補助パネルには控えめな角丸を使い、直線の硬さを和らげる（角丸は浅めにする）
- ページ末尾のイベント情報は黒塗りではなく、淡いウォームグレーのパネルで見せる
- 日本語本文は16px以上を基本とする
- モバイルではカードや2列レイアウトを1列に変える

## 8. 技術方針

- Astroの静的サイトとして実装する
- 初期段階では追加フレームワーク・UIライブラリを導入しない
- GitHub Pagesのプロジェクトサイトとして公開する
- 公開URL: `https://sloth-babies.github.io/hi2026-tutorial-llm/`
- 公式サイトの配下に見えないよう、サイト内の識別表記は `HI2026 - COURSE 03` とする
- 講師、資料、演習リンクなど更新頻度の高い情報は、ページ本体から分離したデータとして管理する
- 推奨データファイル: `src/data/course.ts`
- 外部リンクは新しいタブで開き、`rel="noreferrer"` を付ける
- ページタイトル、description、OGPの最低限のメタデータを設定する

## 9. 受け入れ条件

- ページを開いてすぐにコース名・日時・Colab導線が分かる
- RAG用Colabが正しいURLで開く
- 後から演習リンクを追加してもレイアウトを大きく変更せずに済む
- 講師紹介とホームページリンクが正しく表示される
- PDFリンクが公開時に正しく開く
- 公式シンポジウムサイトへ移動できる
- `npm run build` が成功する
- 主要な画面幅で内容が切れたり重なったりしない
